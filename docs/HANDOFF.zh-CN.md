# 给卢萌团队的交接说明

本包的目的，是把已有科研成果接到研究者常用的大模型客户端。团队无需移交原始数据、共享服务器管理员账号，也无需采用交付方的 Cloudflare 账号。

## 建议先这样验收

1. 下载 Release 压缩包或克隆仓库；按 README 在本机启动。先运行合成测试，再按需运行官网小样本。
2. 指定一位数据负责人核对：脑区名称、基因表达单位、两种加权规则、细胞和供体数量口径，以及哪些摘要允许对外返回。
3. 按数据格式准备一份团队批准的汇总包，在实验室服务器上只读挂载；用 `check-bundle.ts` 检查格式和文件校验和。
4. 先发放少量个人访问密钥，核对真实研究问题的回包与来源；按本团队服务政策设置每日配额。
5. 需要浏览器授权登录时再接 Cloudflare。完成 HTTPS、账号撤销、配额、日志保留和必要的并发测试后，由团队决定何时正式开放。

## 团队需要提供什么

最小交付是一份经过批准的**数据集目录和预计算汇总**，不是全部原始矩阵。

| 内容 | 必须明确的字段 | 没有时的行为 |
| --- | --- | --- |
| 数据版本说明 | 版本 ID、生成时间、来源、允许的访问范围、授权依据 | 不应对外上线；本地验证版不能挂到公网 origin |
| 数据集目录 | ID、名称、来源；可补充脑区、疾病、样本类型、年龄范围、细胞数、供体数 | 未提供的数量为 null，分类列表为空 |
| 表达汇总 | 基因、脑区、细胞类型或 null、加权方式、单位、均值、检出比例、支撑细胞/供体数 | 缺失返回 null；没有记录返回 NO_MATCH |
| 脑区资料 | 命名体系、统计范围、数量；只有真实联合统计才能填写细胞类型组成 | 不用总体细胞类型比例替代脑区组成 |
| 论文证据卡 | 原文位置/链接、作者主张、实际验证依据、推断、发表状态 | 不把官网文字包装成同行评议证据 |
| 可下载文件 | 文件 ID、白名单路径、SHA-256、字节数、适用条款 | 未登记的文件不能下载 |

格式以 [数据约定](DATA-CONTRACT.zh-CN.md) 和 `src/schema.ts` 为准。可以先只交目录，其他记录数组为空；六个工具仍在，但会返回 NO_MATCH。当前实现读取 JSON 汇总包；如团队已有数据库，可在实验室内替换 `select()` 的读取层，保持六个接口和输出语义。该数据库适配属于团队接入工作，本包没有声称已连接团队内部数据库。

## 数据不离开服务器，准确说是什么意思

- 原始矩阵、供体明细、未公开成果和模型权重可以留在实验室；本服务只读取事先批准的目录和结果。
- 调用工具必须把允许返回的结果发送给调用方。大模型客户端或云模型供应商可能会处理这些结果，不能同时承诺“远程大模型看见结果”和“任何结果都不出实验室”。
- 可选 Cloudflare 入口也会处理查询参数和返回摘要，但代码不把科研内容写入 Cloudflare D1/KV。D1/KV 只存登录、授权等状态；实验室 SQLite 只存用户编号、工具名、状态、时间与调用计数。
- 若使用实验室内网客户端和内网模型，可不部署 Cloudflare。若需要公网客户端，又没有公开入站端口，可由团队自行设置 [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/)，它仍会传输获准的网络流量。
- 本版所有获准用户访问同一个汇总包；若需要按项目、疾病或机构隔离内容，先建立独立服务/数据包，或开发明确的数据权限层，不能只靠提示词。

## 本轮验证的结论边界

官网样本的 API → 本地整理 → MCP 查询 → 导出校验链路通过。没有重新训练或验证 DigitalBrain-M1，也没有复现论文的生物学结论。当前预计算表达是跨研究全局汇总，不提供病例对照差异分析。部署到团队真实服务器、接入自有数据和最终上线验收由团队在接收后执行。
